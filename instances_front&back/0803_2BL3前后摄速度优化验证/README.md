# 2BL3前后摄速度优化验证实例

该实例是当前2BL3板端图像算法的自包含快照，用于在上位机逐帧验证速度优化后是否出现漏检或误识别。

- `algorithm/Image`直接复制当前板端`image.c`、参数表和地平线库。
- `algorithm/host`只负责提供摄像头与Flash桩函数、传入姿态高度并转换显示坐标。
- B0、B1和CAR0直接来自每帧板端`g_image_data`，适配层不再增加候选过滤、重新排序或额外时序预测。
- 每次视频回放均逐帧调用`image_horizon_update()`和`image_update()`，与单片机运行顺序一致。

上位机点击“加载实例”，选择本文件夹即可。
