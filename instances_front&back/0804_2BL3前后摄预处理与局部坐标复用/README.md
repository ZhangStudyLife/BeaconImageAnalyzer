# 2BL3前后摄预处理与局部坐标复用实例

该实例基于`0x20260957`继续优化局部灰度特征访存，不修改任何识别参数、候选规则、坐标极性或时序逻辑。

## 结构优化

- 每个15×15局部窗口只预计算15个X镜像坐标和15个Y镜像坐标。
- 局部像素扫描直接通过行指针和坐标表访问，不再对每个像素重复执行两组边界反射判断。
- 画面边缘仍使用完全相同的镜像坐标，环带中位数、径向衰减、几何矩和形状判定不变。
- 保留`0x20260957`的CM4单遍多阈值预处理与亮像素位图消费。
- 不增加动态内存、位置特判、光照特调或视频专用参数。

算法Build ID为`0x20260958`。

验证结果待标量/CM4语义交叉对拍、ARM交叉编译和性能分析后填写。
