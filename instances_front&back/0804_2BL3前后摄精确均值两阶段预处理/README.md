# 2BL3前后摄精确均值两阶段预处理实例

该实例基于`0x20260960`重新调度CM4预处理，不修改识别参数、候选规则、坐标极性或时序逻辑。

## 结构优化

- 第一遍顺序读图完成精确全图均值、灰度不低于60的亮点位图、车灯位图和镜像积分图。
- 精确均值计算完成后，继续使用原来的`10/30`场景分界；只有暗场或亮场需要连通域补充时，第二遍生成实际使用的80或120灰度位图。
- 不再对每个像素同时计算两套互斥的80和120灰度位图，且只保留一份信标补充位图。
- 中等亮度场景原本就不执行信标连通域补充，现在也不执行第二遍信标阈值扫描。
- 峰值响应、局部特征、车灯、地平线、Top16顺序和最终输出全部保持不变。
- 标量桌面路径继续保留`0x20260960`实现，用于和CM4两阶段路径逐帧交叉对拍。
- 不增加动态内存、位置特判、光照特调或视频专用参数。

算法Build ID为`0x20260963`。

验证结果待11119帧标量/CM4语义对拍、性能测试和ARM反汇编检查后填写。
