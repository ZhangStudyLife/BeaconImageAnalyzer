# 2BL3前后摄信标阈值位图跨帧流水实例

该实例以`0x20260964`为唯一基线，只优化精确场景均值确定前后的信标阈值位图数据流，不修改检测参数、候选规则、坐标极性、时序逻辑或输出接口。

## 结构优化

- 使用上一帧的场景类别作为本帧预处理调度提示，在计算精确均值、60灰度亮点位图和车灯位图的同一遍扫描中同步生成80或120灰度信标位图。
- 只有60灰度亮点组非空时才执行信标阈值比较，低灰度背景仍直接跳过。
- 本帧精确均值计算完成后重新确定真实场景类别；若类别改变，立即用真实阈值完整重建本帧信标位图。
- 上一帧类别只影响选择哪条数学等价的数据路径，不参与识别判断；光照突变帧的最终位图仍与基线逐像素一致。
- 初始化和时序重置后首帧继续走基线精确路径，避免引入未初始化状态。
- 不增加位置特判、视频专用参数、检测阈值、动态内存或新的输出状态。

算法Build ID为`0x20260967`。

验证结果待11119帧标量/CM4语义对拍、性能测试、ARM交叉编译和完整CTest后填写。
