# 2BL3前后摄预处理融合原图积分实例

该实例基于`0x20260957`继续重构CM4稀疏峰值响应的数据流，不修改任何识别参数、候选规则、坐标极性或时序逻辑。

## 结构优化

- CM4在单遍多阈值预处理中同步构建带4像素镜像边框的16位模积分图，不再在峰值阶段第二次遍历整帧。
- 仅在亮像素数量仍可能进入稀疏路径时继续构建积分行；确定进入稠密路径后停止无用积分写入。
- 左右镜像前缀、原始188像素和右侧镜像后缀沿用原顺序；上下镜像行也保持原语义，所有3×3和9×9盒和继续使用原来的四角积分查询。
- CM4额外保留一份约51KB的镜像积分缓冲，使其跨越车灯连通域阶段存活；该版本明确采用固定SRAM换取整帧扫描时间，后续通过链接结果确认容量余量。
- 峰值响应、8邻域极大值、Top16顺序、地平线过滤、车灯屏蔽和局部特征全部保持不变。
- 桌面标量路径仍保留`0x20260957`实现，上位机显示结果用于和CM4语义逐帧交叉对拍。
- 不增加动态内存、位置特判、光照特调或视频专用参数。

算法Build ID为`0x20260960`。

验证结果待11119帧标量/CM4语义对拍、性能测试和ARM反汇编检查后填写。
