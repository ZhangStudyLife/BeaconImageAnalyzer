# 2BL3前后摄局部背景分层中位数实例

该实例基于`0x20260954`重构点光源局部背景中位数计算，不修改检测阈值、候选规则、坐标极性或时序逻辑。

## 结构优化

- 25至49像素半径环带的中位数仍精确计算，不使用采样或近似。
- 首先用16个高四位桶定位中位数所在的灰度段，再仅对目标段统计低四位。
- 将256项直方图清零和可变长度扫描替换为固定的16项分层统计，同时减少候选栈占用。
- 背景、对比度、径向衰减、集中度、形状特征和必要条件短路保持原公式。
- 不增加动态内存、位置特判、光照特调或视频专用参数。

算法Build ID为`0x20260956`。

验证结果待严格编译、11119帧逐帧对拍和多轮性能测试后填写。
