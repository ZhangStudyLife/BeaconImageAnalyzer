# 2BL3前后摄位图间隙与峰值行扫描实例

该实例基于`0x20260946`继续进行通用结构优化，不修改识别阈值、候选规则、坐标极性、时序规则或外部输出接口。

## 结构优化

- 缓存车灯主轴方向向量，在灰度条带验证、信标遮罩、连通域补充和时序遮罩之间复用，避免同一目标重复调用三角函数。
- 上方车灯断点连接不再逐像素寻找黑色短缝，而是按32位前景字遍历真实前景位置。
- 断点连接继续直接使用`car_lamp_bridge_max_gap`，短缝定义、行顺序和填充结果与原算法一致。
- CM4稀疏峰值扫描每次使用`USUB8 + SEL`并行判断4个像素，再按原X顺序处理灰度不低于60的像素。
- 峰值响应、8邻域极大值、Top16排序、地平线过滤和车灯屏蔽公式保持不变。
- 桌面标量路径保留原逐像素循环，CM4专用路径不影响上位机回放语义。
- 不增加动态内存、视频专用参数、固定位置规则或光照场景特判。

算法Build ID为`0x20260954`。

## 验证结果

- 使用四段不同场景视频共11119帧进行逐帧回归。
- 相对`0x20260946`，标量输出、CM4 DSP语义输出以及新版本标量/DSP交叉输出均为0帧差异。
- PC标量多轮交叉顺序测试中，中位耗时由约`69.05 us/帧`降至`63.30 us/帧`，约提升`8.34%`。
- CM4峰值行扫描属于ARM专用优化，不计入上述PC标量提升；数据集中灰度不低于60的像素平均占整帧约`6.38%`。
- Cortex-M4交叉编译通过，反汇编确认包含`USUB8`、`SEL`、`RBIT`和`CLZ`。
- 相对方向缓存版本`0x20260947`，ARM目标代码增加约496字节，BSS保持不变。
- BeaconImageAnalyzer完整构建通过，CTest 6/6通过。

最终是否达到`10 ms/帧`必须在用户确认回放效果、移植板端后，通过板端1000帧计时实测确认。
