# 2BL3前后摄稀疏积分峰值路径实例

该实例根据每帧实际亮像素数量，在两条数学等价的峰值响应路径之间自动选择，不修改任何识别阈值和分类规则。

- 亮像素较少时建立镜像边界积分图，只为可能成为信标的亮像素计算中心及8邻域响应。
- 亮像素较多时继续使用上一实例的稠密纵向列和与横向滑窗，避免积分稀疏路径在复杂亮场退化。
- 两条路径均严格计算`response = 9 × box3_sum - box9_sum`，使用相同Top16、地平线、车灯屏蔽和局部极大值规则。
- 稀疏/稠密切换阈值只依据运算量交叉点，不参与目标分类。
- 连通域工作区和积分图使用同一块互斥Scratch内存，避免额外占用约100 KB RAM。
- 算法Build ID为`0x20260910`。
