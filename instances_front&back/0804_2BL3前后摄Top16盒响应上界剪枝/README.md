# 2BL3前后摄Top16盒响应上界剪枝实例

该实例以`0x20260964`为唯一基线，只增加严格数学上界剪枝，不修改检测参数、候选规则、坐标极性、时序逻辑或输出接口。

## 结构优化

- Top16尚未填满时继续按原顺序计算完整响应。
- Top16填满后，尚未缓存的中心点先只读取3×3积分和。
- 因为9×9区域包含3×3区域且灰度非负，所以：

```text
response = 9 × sum3 - sum9 <= 8 × sum3
```

- 若`8 × sum3`已经不超过当前第16名响应，该点不可能进入Top16，直接跳过9×9积分和及后续邻域响应。
- 上界能够通过时，使用已有3×3和补算9×9和，不重复读取3×3积分。
- 已缓存的响应、8邻域比较、相等响应顺序和Top16插入规则保持不变。
- 不增加动态内存、位置特判、光照特调、视频专用参数或经验阈值。

算法Build ID为`0x20260972`。

理论上该实例必须与基线逐帧完全一致；验证结果待11119帧对拍、性能测试、ARM交叉编译和完整CTest后填写。
