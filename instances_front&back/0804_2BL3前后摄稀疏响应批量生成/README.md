# 2BL3前后摄稀疏响应批量生成实例

该实例以局部特征定点累加版本为基线，将稀疏峰值路径的逐点响应缓存改为需求位图和批量响应生成，不修改识别公式或参数。

- 局部背景中位数只会产生整数或0.5灰度，使用2倍整数可无损表示全部权重。
- 质心、一阶矩、二阶矩、集中度和半高面积在像素循环中使用整数乘加。
- 亮点的3×3响应需求先合并到逐行位图，每个需要的响应只计算一次。
- 局部极大值比较直接读取响应数组，不再逐邻域查询有效位图和重复计算索引。
- 循环结束后恢复原浮点量，继续执行完全相同的协方差、特征和阈值公式。
- 稠密路径、局部特征、车灯、地平线和时序逻辑保持不变。
- 算法Build ID为`0x20260925`。
