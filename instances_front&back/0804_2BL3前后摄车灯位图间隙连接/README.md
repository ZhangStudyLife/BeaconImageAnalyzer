# 2BL3前后摄位图原生统一预处理实例

该实例基于`0x20260946`，缓存车灯主轴方向向量，并在灰度条带验证、峰值遮罩、连通域补充与时序遮罩之间复用，不修改识别阈值、候选规则、坐标极性、时序规则或输出接口。

- 连通域直接消费32位前景图，不再把整帧二值图作为访问状态表。
- 前景源图保持不可变，访问工作图按位清除；局部灰度特征仍能读取与旧算法完全相同的阈值区域。
- 扫描线洪泛使用按字查找下一前景位，跳过相邻行中的连续背景区间。
- 同一预处理阶段生成车灯与信标补充连通域位图，车灯时序补检复用已生成的车灯位图。
- 稀疏积分路径在计算响应前执行地平线必要条件，并将数学等价的稀疏/稠密调度分界提高到60%；极端高亮帧仍保留稠密路径兜底。
- 连通域只采集面积、边界、质心和整数二阶矩；主次轴与伸长率在确实读取时才计算。
- 主轴角度进一步独立惰性计算，未进入车灯灰度条带验证的连通域不执行`atan2f`。
- 可选`IMAGE_HOST_PROFILE`只用于统计连通域、主次轴和角度计算次数，正常实例和板端构建不包含统计开销。
- 不增加位置特判、视频专用参数、动态内存或外部接口。
- 算法Build ID为`0x20260947`。

## 当前验证

- 四段通用视频共11119帧，相对`0x20260944`的标量结果、DSP结果以及新版本标量/DSP交叉结果均为0帧差异。
- 统计得到平均每帧遍历8.64个连通域，仅1.19个需要主次轴，0.66个需要角度；形状计算覆盖率约13.8%。
- 独立顺序回放十轮的标量PC中位耗时由`69.68 us/帧`降至`64.67 us/帧`，约提升`7.18%`；CM4 DSP桌面语义仿真只用于结果对拍，不作为ARM速度结论。
- Cortex-M4交叉编译通过；`image.c`目标代码由27492字节降至27148字节，BSS由95329字节增至101089字节，即代码减少344字节、固定工作位图增加5760字节。
- 最终性能和ARM静态结果以本轮验证记录为准；是否达到10 ms必须在用户确认回放后移植板端，并重新执行1000帧实测。
