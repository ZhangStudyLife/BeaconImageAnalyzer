# 2BL3前后摄局部灰度特征跨阶段复用实例

该实例以`0x20260964`为唯一基线，只优化同一候选在峰值分类和最终可靠性分类之间的数据复用，不修改识别参数、候选规则、坐标极性、时序逻辑或输出接口。

## 结构优化

- 峰值候选第一次执行局部灰度特征计算时，保存完整特征结果。
- 候选坐标细化后仍落在原像素时，最终可靠性检查直接复用已有结果，避免再次扫描同一局部窗口。
- 坐标细化到其他像素、来自连通域补充或没有完整缓存时，继续按原逻辑重新计算，保证取样中心完全一致。
- 候选去重、面积排序、B0/B1选择、车灯屏蔽和地平线过滤均保持原顺序。
- 不增加动态内存、位置特判、光照特调、视频专用参数或新的识别分支。

算法Build ID为`0x20260966`。

验证结果待11119帧标量/CM4语义对拍、性能测试、ARM交叉编译和完整CTest后填写。
