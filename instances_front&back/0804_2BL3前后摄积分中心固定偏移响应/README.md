# 2BL3前后摄积分中心固定偏移响应实例

该实例基于稳定基线`0x20260964`，仅优化信标局部响应的积分图地址计算，不修改识别参数、候选规则、坐标极性或时序逻辑。

## 结构优化

- 删除通用积分框求和函数中每次调用重复执行的上下左右坐标计算。
- 每个响应只计算一次积分图中心地址。
- 3×3和9×9框的四角地址改为编译期固定偏移，使ARM编译器可以直接生成常量偏移访存。
- 保留原有镜像积分图、稀疏响应缓存、阈值位图和连通域遍历顺序。
- 不增加动态内存、位置特调、光照特调或视频专用参数。

算法Build ID为`0x20260973`。

## 验证结果

- 4段历史视频共11119帧，基线标量、新标量、基线CM4 DSP语义和新CM4 DSP语义三组对拍均为零差异。
- ARM缓存未命中路径由4次行跨度乘法降为1次`MLA`，函数代码明显缩短。
- PC标量和DSP语义性能没有形成稳定普遍收益，因此该实例只保留为单项实验，不作为最终主线。
