# 2BL3前后摄ARM固定偏移综合候选实例

该实例以稳定基线`0x20260964`的识别行为为准，组合三项已独立验证的数学等价优化，不修改检测参数、候选规则、坐标极性、时序逻辑或输出接口。

## 结构优化

- 极稀疏帧直接计算亮点邻域真正需要的3×3/9×9盒响应，跳过整帧镜像积分图构建。
- 普通稀疏帧使用原16位模积分图，一次计算并缓存相邻两个X响应，利用`SSUB16/SADD16`降低积分图读事务。
- 单响应和双响应积分求和都只计算一次中心地址，3×3与9×9四角改用编译期固定偏移，减少CM4缓存未命中路径中的行跨度乘法和地址运算。
- 三条路径都严格执行`9 × sum(3×3) - sum(9×9)`，共享原响应缓存、局部极大值、Top16和后续分类。
- 亮点密度只决定数学等价的计算路径；跨过成本分界时在当前帧补建所需积分图，不使用近似结果。
- 不增加动态内存、位置特判、光照特调、视频专用参数或检测阈值。

算法Build ID为`0x20260974`。

## 验证结果

- 4段历史视频共11119帧，基线标量、新标量、基线CM4 DSP语义和新CM4 DSP语义三组对拍均为零差异。
- ARM双响应缓存未命中函数由约`0xE8`缩短至`0xCC`，减少地址运算和寄存器占用；对象代码比`0x20260970`减少76字节，BSS不变。
- 与稳定基线交替执行7轮PC CM4 DSP语义测试，4段视频中位耗时分别改善约`7.8%`、`2.3%`、`3.5%`和`2.5%`。
- 固定偏移相对`0x20260970`的PC增量较小且受平台噪声影响，最终ARM实机收益仍需在用户确认识别效果后移植板端并用DWT测量。
