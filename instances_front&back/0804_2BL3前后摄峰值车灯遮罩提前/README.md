# 2BL3前后摄峰值车灯遮罩提前实例

该实例基于`0x20260964`调整稀疏峰值路径的纯拒绝条件顺序，不修改识别参数、候选规则、坐标极性或时序逻辑。

## 结构优化

- 亮点通过地平线必要条件后，立即检查当前车灯、时序车灯及其向下拖影遮罩。
- 位于任一车灯遮罩内的中心点原本最终必定被丢弃，现在不再计算中心及8邻域的3×3/9×9积分响应。
- 遮罩外亮点仍使用原响应、原局部极大值比较顺序和原Top16插入顺序。
- 积分响应缓存仅是性能状态，不参与分类；调整计算先后不会改变其他中心点按需获得的响应值。
- 保留`0x20260964`的精确均值、稀疏信标阈值和镜像积分融合。
- 不增加动态内存、位置特判、光照特调或视频专用参数。

算法Build ID为`0x20260965`。

验证结果待11119帧标量/CM4语义对拍、性能测试和ARM反汇编检查后填写。
