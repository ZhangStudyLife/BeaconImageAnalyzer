# 2BL3前后摄双响应积分缓存实例

该实例以`0x20260964`为唯一基线，只优化CM4稀疏积分峰值路径中相邻响应的计算与缓存，不修改检测参数、候选规则、坐标极性、时序逻辑或输出接口。

## 结构优化

- 请求一个尚未缓存的响应时，以偶数X为起点同时计算并缓存相邻两个响应。
- 3×3和9×9积分矩形的相邻两个结果分别打包在两个16位半字中，使用`SSUB16/SADD16`完成模16位包含排除运算。
- 两个响应仍分别执行`9 × sum(3×3) - sum(9×9)`，数值与原逐点实现完全一致。
- 响应有效位按相邻两位同时更新；原Y、X扫描顺序、8邻域比较顺序和Top16插入顺序不变。
- 标量桌面路径保持原逐点实现，用于与CM4语义路径交叉对拍。
- 不增加动态内存、位置特判、光照特调、视频专用参数或检测阈值。

算法Build ID为`0x20260969`。

验证结果待11119帧标量/CM4语义对拍、性能测试、ARM交叉编译和完整CTest后填写。
