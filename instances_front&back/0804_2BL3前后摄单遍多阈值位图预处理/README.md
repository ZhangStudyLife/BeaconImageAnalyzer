# 2BL3前后摄单遍多阈值位图预处理实例

该实例基于`0x20260954`重构CM4每帧首次整图预处理，不修改任何识别参数、候选规则、坐标极性或时序逻辑。

## 结构优化

- CM4在同一次顺序读图中同时完成全图灰度和、60灰度亮像素统计、车灯位图及80/120灰度信标补充位图。
- 明暗场景只在预处理完成后选择对应位图，阈值和原判定保持不变。
- 每32像素在寄存器中组装完整位图字后一次写回，避免每4像素对同一存储字进行读-改-写。
- 稀疏峰值扫描直接消费60灰度位图，不再第三次遍历原图重复比较亮像素。
- 积分响应、8邻域极大值、Top16顺序、车灯遮罩和地平线公式完全不变。
- 桌面标量路径保持`0x20260954`原实现；上位机所见输出与板端CM4语义逐帧对拍。
- 不增加动态内存、位置特判、光照特调或视频专用参数。

算法Build ID为`0x20260957`。

验证结果待标量/CM4语义交叉对拍、ARM交叉编译和性能分析后填写。
