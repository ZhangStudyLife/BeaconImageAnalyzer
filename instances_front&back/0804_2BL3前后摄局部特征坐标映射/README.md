# 2BL3前后摄局部特征坐标映射实例

该实例以局部特征定点累加版本为基线，在每个候选开始时预计算15项X/Y镜像坐标，局部像素循环直接索引，不修改识别公式或参数。

- 局部背景中位数只会产生整数或0.5灰度，使用2倍整数可无损表示全部权重。
- 质心、一阶矩、二阶矩、集中度和半高面积在像素循环中使用整数乘加。
- 边缘反射从每像素两次边界判断改为每候选30项坐标预计算。
- 循环结束后继续执行完全相同的协方差、特征和阈值公式。
- 稠密路径、局部特征、车灯、地平线和时序逻辑保持不变。
- 算法Build ID为`0x20260923`。
