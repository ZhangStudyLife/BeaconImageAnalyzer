# 2BL3前后摄CM4亮像素位扫描实例

该实例基于CM4位图乘法压缩版本，只优化稀疏峰值路径的像素调度，不修改任何检测阈值、候选规则或输出接口。

- 场景均值扫描在统计亮像素数量的同时生成逐行亮像素位图，不增加第二次全图扫描。
- 稀疏峰值路径按32位字遍历位图，只访问灰度达到点光源最低峰值要求的像素。
- 使用`RBIT+CLZ`按X坐标升序提取置位像素，保持候选访问顺序不变。
- 标量桌面路径保持原实现，用于与CM4 DSP路径逐帧对拍。
- 不增加场景参数、位置特判或光照特调规则。
- 算法Build ID为`0x20260945`。

## 验证结论

- 四段通用视频共11119帧，相对`0x20260944`的标量结果、DSP结果以及新版本标量/DSP交叉结果均为0帧差异。
- MinGW严格编译和Cortex-M4交叉编译通过，反汇编确认生成`RBIT/CLZ`位扫描指令。
- 新增亮像素位图占用2880字节BSS。
- 桌面DSP语义仿真中整体耗时稳定增加约9%；虽然该结果不能直接代表CM4周期，但结合额外内存和代码膨胀，当前证据不足以将其作为后续基线。

该实例仅保留为等价性实验，不建议移植板端。后续优化继续以`0x20260944`为基线。
