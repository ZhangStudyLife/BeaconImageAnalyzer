# 2BL3前后摄稀疏响应按行批量生成实例

该实例基于`0x20260960`重构CM4稀疏峰值响应调度，不修改识别参数、候选规则、坐标极性或时序逻辑。

## 结构优化

- 根据灰度不低于60的中心像素位图，按响应行合并其3×3邻域的全部响应需求。
- 每个真正需要的3×3/9×9盒响应每帧只计算一次，并写入4行环形响应缓冲。
- 峰值判断直接读取已经生成的上、中、下三行响应，不再为每个亮点执行9次有效位查询、槽位计算和位掩码更新。
- 亮点仍按原来的Y、X升序访问；响应阈值、8邻域比较顺序、Top16插入顺序、地平线和车灯遮罩保持不变。
- 标量桌面路径继续保留`0x20260960`的逐点缓存实现，用于和CM4批量路径逐帧交叉对拍。
- 保留单遍多阈值预处理和镜像积分融合，不增加动态内存、位置特判、光照特调或视频专用参数。

算法Build ID为`0x20260962`。

验证结果待11119帧标量/CM4语义对拍、性能测试和ARM反汇编检查后填写。
