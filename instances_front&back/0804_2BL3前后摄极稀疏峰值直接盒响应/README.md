# 2BL3前后摄极稀疏峰值直接盒响应实例

该实例以`0x20260964`为唯一基线，只优化极稀疏画面的3×3/9×9峰值响应计算路径，不修改检测参数、候选规则、坐标极性、时序逻辑或输出接口。

## 结构优化

- 当本帧灰度不低于60的像素不超过实现成本分界时，只计算亮点3×3邻域真正需要的盒响应，不再为整帧构建镜像积分图。
- 图像内部使用`USADA8`一次累加4个像素，边缘继续使用与原算法相同的镜像坐标。
- 响应公式仍为`9 × sum(3×3) - sum(9×9)`，响应缓存、8邻域极大值、Top16顺序和后续分类完全不变。
- 亮点增多时自动回到原16位模积分图路径；路径切换仅影响计算方式，不参与检测判断。
- 使用上一帧的路径作为预处理调度提示；若本帧密度跨过分界，当前帧会补建所需积分图，结果不依赖预测是否正确。
- 初始化和时序重置后首帧继续走基线积分图路径。
- 不增加动态内存、位置特判、光照特调、视频专用参数或检测阈值。

算法Build ID为`0x20260968`。

验证结果待不同成本分界的等价性、11119帧标量/CM4语义对拍、性能测试、ARM交叉编译和完整CTest后填写。
