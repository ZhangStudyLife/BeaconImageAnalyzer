# 2BL3前后摄原灰度局部极大值前筛实例

该实例以`0x20260964`为基线，在昂贵的3×3/9×9盒响应之前增加点光源原始灰度必要特征实验，不修改后续响应公式、局部特征参数、坐标极性、时序逻辑或输出接口。

## 结构实验

- 灰度不低于60的中心像素必须不低于其3×3邻域的其他8个像素，才继续计算盒响应。
- 使用“不低于”而不是“严格大于”，因此饱和平台和并列峰仍全部保留。
- 稀疏积分路径、标量路径和稠密路径使用同一规则，避免计算路径影响检测语义。
- 通过前筛的像素继续执行原`9 × sum(3×3) - sum(9×9)`、响应局部极大值、Top16和全部灰度形状分类。
- 该规则来自点光源应具有局部亮核的通用成像特征，不使用位置、视频、环境光或特定样本参数。

算法Build ID为`0x20260971`。

该实例允许回放结果变化，只有在历史视频变化足够小且标注样本不退化时才会继续；否则直接淘汰。
