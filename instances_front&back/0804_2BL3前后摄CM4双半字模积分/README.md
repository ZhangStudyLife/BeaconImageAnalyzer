# 2BL3前后摄CM4双半字模积分实例

该实例基于车灯前景位图调度版本，只优化CM4上的16位模积分图写入，不修改桌面标量公式、检测参数或输出规则。

- 积分行增加一个未使用的16位对齐槽，使每行保持4字节对齐。
- CM4路径先计算相邻两个行前缀，再使用`SADD16`同时叠加上一积分行的两个16位值。
- 每次循环完成两个积分列，减少循环控制、上一行加载和当前行存储次数。
- 左右镜像序列与标量路径逐像素完全一致。
- 16位自然回绕及3×3、9×9窗口和语义保持不变。
- 桌面实例仍执行可读的标量实现；DSP仿真路径用于逐帧等价验证。
- 算法Build ID为`0x20260941`。
