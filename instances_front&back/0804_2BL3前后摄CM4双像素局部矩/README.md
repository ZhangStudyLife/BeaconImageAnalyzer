# 2BL3前后摄CM4双像素局部矩实例

该实例基于`0x20260957`优化局部灰度几何矩累加，不修改识别参数、候选规则、坐标极性或时序逻辑。

## 结构优化

- CM4将相邻两个像素的非负灰度权重打包为两个16位半字。
- 总权重、质心一阶矩、协方差二阶矩和内环权重使用`SMLAD`双16位乘累加，每条指令同时处理两个像素。
- 整数权重、像素顺序、累加量纲和浮点特征转换保持不变。
- 桌面标量路径保持`0x20260957`原实现，CM4仿真路径与标量路径逐帧交叉验证。
- 保留CM4单遍多阈值预处理与亮像素位图消费。
- 不增加动态内存、位置特判、光照特调或视频专用参数。

算法Build ID为`0x20260959`。

验证结果待标量/CM4语义交叉对拍、ARM交叉编译和性能分析后填写。
