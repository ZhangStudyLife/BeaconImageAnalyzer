# 2BL3前后摄亮点位图稀疏信标阈值实例

该实例基于`0x20260963`优化第二阶段信标阈值位图生成，不修改识别参数、候选规则、坐标极性或时序逻辑。

## 结构优化

- 80和120灰度阈值都严格高于第一阶段已有的60灰度亮点门槛，因此第二阶段只访问亮点位图覆盖的4像素组。
- 每个32位亮点字使用`RBIT+CLZ`定位下一个非空4像素组，连续跳过整组低灰度背景。
- 被访问的4像素组仍使用原来的`USUB8+SEL`并行比较，并按原X位置写入信标连通域位图。
- 最终位图逐像素等价于全图执行80或120灰度比较；阈值、场景均值分界和连通域遍历顺序不变。
- 保留`0x20260963`的精确均值两阶段调度和镜像积分融合。
- 不增加动态内存、位置特判、光照特调或视频专用参数。

算法Build ID为`0x20260964`。

验证结果待11119帧标量/CM4语义对拍、性能测试和ARM反汇编检查后填写。
