# 2BL3前后摄CM4 DSP峰值流水线实例

该实例以局部特征定点累加版本为基线，为IAR Cortex-M4构建增加DSP并行数据路径；桌面回放使用数学等价的标量路径，不修改识别公式或参数。

- 局部背景中位数只会产生整数或0.5灰度，使用2倍整数可无损表示全部权重。
- 质心、一阶矩、二阶矩、集中度和半高面积在像素循环中使用整数乘加。
- CM4使用`USADA8`每次累计4个灰度，并统计峰值最低灰度像素数量。
- CM4使用`USUB8 + SEL`每次生成4个二值像素，覆盖通用、车灯和信标阈值图。
- 3行与9行纵向和打包在同一个32位字中，使用`SADD16/SSUB16`并行更新两路盒滤波。
- 循环结束后恢复原浮点量，继续执行完全相同的协方差、特征和阈值公式。
- 稠密路径、局部特征、车灯、地平线和时序逻辑保持不变。
- 算法Build ID为`0x20260926`。

## 验证结果

- 四段通用回放共11119帧，相对`0x20260912`的B0/B1、CAR0及全部时序结果为0帧差异。
- 桌面强制执行CM4 DSP仿真路径后，与标量路径仍为0帧差异。
- Cortex-M4交叉编译通过，反汇编确认生成`USADA8`、`USUB8`、`SEL`、`SADD16`和`SSUB16`指令。
- BeaconImageAnalyzer完整构建通过，CTest 6/6通过。
- 桌面端仅能度量定点特征部分，整体约提升2%至3%；DSP路径的真实收益需要用户确认回放效果后移植板端，以1000帧平均耗时验证。
