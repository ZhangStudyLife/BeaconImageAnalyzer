# 2BL3前后摄局部背景两级中位数实例

该实例以局部特征定点累加版本为基线，将环带背景中位数从256项完整直方图改为精确的两级16桶统计，不修改识别公式或参数。

- 局部背景中位数只会产生整数或0.5灰度，使用2倍整数可无损表示全部权重。
- 质心、一阶矩、二阶矩、集中度和半高面积在像素循环中使用整数乘加。
- 先用灰度高4位定位中位数所在桶，再仅统计目标桶低4位，结果与256项直方图一致。
- 循环结束后恢复原浮点量，继续执行完全相同的协方差、特征和阈值公式。
- 稠密路径、局部特征、车灯、地平线和时序逻辑保持不变。
- 算法Build ID为`0x20260924`。
