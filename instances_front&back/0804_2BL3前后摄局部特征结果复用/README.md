# 2BL3前后摄局部特征结果复用实例

该实例基于`0x20260954`继续进行数据流优化，不修改任何检测参数、候选规则、坐标极性或时序逻辑。

## 结构优化

- 峰值候选在首次执行15×15局部灰度特征时，保存已完整计算的特征结果。
- 候选坐标细化后仍落在原像素时，最终可靠性检查直接复用该结果，不再重复扫描局部窗口。
- 候选细化到其他像素或来自连通域补充时，仍按原逻辑重新计算，确保取样中心不变。
- 特征公式、阈值比较顺序和B0/B1面积排序保持不变。
- 不增加动态内存、视频专用参数、位置特判或光照特调。

算法Build ID为`0x20260955`。

验证结果待严格编译、11119帧逐帧对拍和多轮性能测试后填写。
