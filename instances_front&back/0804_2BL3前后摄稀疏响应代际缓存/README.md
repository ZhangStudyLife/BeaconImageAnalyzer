# 2BL3前后摄稀疏响应代际缓存实例

该实例以稀疏响应缓存版本为基线，将响应值和帧代际合并到单个32位缓存项，不修改识别公式或参数。

- 每个图像坐标的积分响应在一帧内最多计算一次。
- 单次缓存访问不再计算位图字节和位掩码。
- 使用16位帧代际判断缓存有效性，取消每帧清空有效位图。
- 代际回绕时才清空缓存，正常运行65535帧内不产生额外整图清零。
- 中等亮度场景也可选择稀疏路径；路径选择只影响运算量，不影响输出。
- 稠密路径、局部特征、车灯、地平线和时序逻辑保持不变。
- 算法Build ID为`0x20260918`。
