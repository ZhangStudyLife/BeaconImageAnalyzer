# 2BL3前后摄连通域原地消费实例

该实例在稀疏积分峰值路径基础上，重构车灯和补充信标共用的连通域遍历，不修改阈值、连通方式、形状统计或候选规则。

- 二值图中的像素在进入队列时直接清零，清零状态同时表示“已访问”。
- 删除独立的188×120访问标记图和每次二值化后的整图清零操作。
- 邻域扩展由“读取二值图＋读取访问图”缩减为只读取二值图。
- 灰度车灯验证直接按原120灰度阈值读取原图，保持原二值图筛选语义。
- 连通域仍使用8邻域、相同队列顺序以及相同面积、质心、长短轴和角度公式。
- 算法Build ID为`0x20260911`。
