# 2BL3前后摄整图预处理融合实例

该实例以稀疏响应缓存版本为基线，合并首次整图预处理，并复用同一遍扫描得到的稀疏亮像素坐标，不修改识别公式或参数。

- 全图均值、亮像素统计和首次车灯二值化在同一次扫描内完成。
- 稀疏路径直接遍历预处理阶段记录的亮像素，不再重新扫描188×120整幅图。
- 亮像素使用16位打包坐标，避免逐点除法和取模，数据布局也便于后续板端DSP优化。
- 原有积分响应缓存继续保证每个图像坐标一帧内最多计算一次。
- 稠密路径、局部特征、车灯、地平线和时序逻辑保持不变。
- 算法Build ID为`0x20260917`。
