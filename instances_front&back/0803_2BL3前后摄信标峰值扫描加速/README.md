# 2BL3前后摄信标峰值扫描加速实例

该实例以当前2BL3板端等效实例为基线，只优化信标灰度响应峰值扫描，不修改检测公式、阈值、候选规则、时序逻辑、地平线、车灯算法和输出接口。

- `algorithm/Image`保留完整板端图像算法快照。
- 每帧仍依次调用`image_horizon_update()`和`image_update()`。
- B0、B1和CAR0直接来自`g_image_data`，桌面适配器只转换显示坐标。
- `gray_find_box_peaks()`使用纵向3行/9行列和与横向滑窗，一次生成完全相同的3×3和9×9盒响应。
- 算法Build ID为`0x20260907`。

在上位机中点击“加载实例”，选择本目录即可逐帧查看实际算法输出。
