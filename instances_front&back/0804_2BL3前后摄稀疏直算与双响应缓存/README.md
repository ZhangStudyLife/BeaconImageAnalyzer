# 2BL3前后摄稀疏直算与双响应缓存实例

该实例组合两个已经独立验证为逐帧等价的CM4响应计算策略，仍以`0x20260964`的识别行为为基准，不修改任何检测参数、候选规则、坐标极性、时序逻辑或输出接口。

## 结构优化

- 极稀疏帧直接计算亮点邻域真正需要的3×3/9×9盒响应，跳过整帧镜像积分图构建。
- 普通稀疏帧继续使用原16位模积分图，但一次计算并缓存相邻两个X响应，使用`SSUB16/SADD16`降低积分图读事务。
- 两条路径都严格执行`9 × sum(3×3) - sum(9×9)`，共享原响应缓存、局部极大值、Top16和后续分类。
- 亮点密度只决定数学等价的计算路径；跨过成本分界时会在当前帧补建所需积分图，不使用近似结果。
- 标量桌面路径保持基线实现，用于与CM4语义路径逐帧交叉对拍。
- 不增加动态内存、位置特判、光照特调、视频专用参数或检测阈值。

算法Build ID为`0x20260970`。

验证结果待11119帧标量/CM4语义对拍、ARM静态检查、性能分析和完整CTest后填写。
