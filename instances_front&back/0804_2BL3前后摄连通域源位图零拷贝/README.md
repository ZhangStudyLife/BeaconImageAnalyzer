# 2BL3前后摄连通域源位图零拷贝实例

该实例基于`0x20260960`继续重构连通域数据流，不修改任何识别参数、候选规则、坐标极性或时序逻辑。

## 结构优化

- 连通域源图直接指向预处理阶段生成的车灯或信标位图，只把可消费的访问状态复制到独立工作位图。
- 上方车灯短间隙直接写回车灯源位图和访问位图，后续时序车灯补检继续复用同一份桥接结果。
- 取消车灯主检前的源位图复制、桥接后的反向复制，以及车灯补检和信标补充阶段的重复源图复制。
- 扫描线洪泛仍只清除访问工作位图；面积、边界、整数矩、行优先发现顺序和8连通语义保持不变。
- 仍保留内部临时源位图，供旧的按阈值临时连通域入口使用，避免改变其源码兼容行为。
- 保留`0x20260960`的单遍多阈值预处理和镜像积分融合。
- 不增加动态内存、位置特判、光照特调或视频专用参数。

算法Build ID为`0x20260961`。

验证结果待11119帧标量/CM4语义对拍、性能测试和ARM反汇编检查后填写。
