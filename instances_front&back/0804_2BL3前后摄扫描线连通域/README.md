# 2BL3前后摄扫描线连通域实例

该实例基于`0x20260930`，只重构公共连通域遍历器，不修改任何识别阈值、候选规则、地平线、时序或输出接口。

- 使用水平扫描线洪泛替代逐像素8邻域BFS。
- 仍采用严格8连通语义，相邻行搜索范围为当前扫描线左右各扩1像素。
- 每条扫描线使用整数公式累计面积、质心和二阶矩，最终协方差、主次轴及角度公式保持不变。
- 连通域仍按图像行优先顺序被消费，不改变候选发现顺序。
- 固定内存，无动态分配、递归、等待或新增参数。
- 算法Build ID为`0x20260933`。

该方案属于数据结构与遍历方式优化，目标是同时降低车灯检测、信标连通域补充和时序车灯补检成本。
