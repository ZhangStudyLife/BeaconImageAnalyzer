# 前后双车灯离线实例

本目录包含前后双车灯结构的两个自包含离线实例：

- `前后摄`：基于 `0804-张跃哲优化-fcb0e1befe4addf384e84af5142ff75f5a0fc099`，Build ID `0x20261001`。
- `下摄`：基于 `0801_下摄原始灰度信标草稿`，Build ID `0x20261002`。

两个实例都提供可选接口：

```c
void beacon_image_set_car_lamp_mode(unsigned char mode);
```

`mode=1` 为单车灯，`mode=2` 为双车灯。初始化默认单车灯。动态结果结构没有变化，上位机原有的 4 个车灯槽位继续用于兼容；本功能最多使用其中两个。

双车灯模式会把两块当前帧已测量且已配对灯板的旋转边界连接成车体遮罩。任一灯板仅剩时序预测时不建立连接区，单灯仍使用原遮罩方式。遮罩按图像行预计算左右边界，后续候选判断只做边界比较，不进行逐像素多边形求交。

上位机的主回放窗口和 TCP Raw 窗口均可切换模式。切换会清除算法时序和帧缓存，离线回放从第 0 帧按因果顺序重建到当前帧，TCP Raw 从当前帧重新建立轨迹。画面统一显示 `CAR`，不赋予车头/车尾含义；CSV 仍保留 `target_index=0/1` 和 `group_id=car0/car1`。

本目录保存离线算法实例及验证材料。对应前后摄双灯算法已迁移到 2BL3 真机固件，SPI v4 可传输两个车灯；当前 4BB7 控制链仍只使用槽 0，下摄双灯算法和双灯车辆中心融合留待后续阶段。

完整验证记录见 [验证清单.md](验证清单.md)。
