# 0813 100 Hz 前后摄实例

该实例来自 `CYT2BL3_Image` 提交
`103e053259c5d549b0abe85e4d3db9705ef07e35`，用于在
BeaconImageAnalyzer 中离线运行与板端一致的前后摄图像算法。

## 板端快照

`algorithm/Image` 中以下文件以该提交的 `project/code/Image` 为基础：

- `image.c`
- `image.h`
- `image_data.h`
- `image_horizon.c`
- `image_horizon.h`
- `image_params.c`

算法 Build ID 为 `0x20260977`，共导出 57 项运行参数。摄像头曝光默认值
为该提交驱动中的 `500`。

相对原始快照，本实例与板端同步增加一条最终输出过滤：图像坐标 `y >= 90`
且连通域面积 `< 6` 的信标候选不输出，预测轨迹同样遵守该条件。参数、地平线
模型和整图处理流程保持不变。

本版本还增加暗场远距离弱信标检测。原强信标路径继续使用 `>= 60` 灰度和
16 个峰值，不改变既有 B0/B1；仅在整图均值 `< 10` 时，同一次响应扫描额外
保留上半区最多 8 个弱峰。弱峰需满足暗背景、紧凑点源形状，并在 6 像素门限内
跟踪。原有“累计命中 5 次且最近 3 次响应范围不超过 100”的确认路径保持不变；
另对图像上方 `y <= 40`、响应不低于 `3000` 的远灯增加 5 帧内命中至少 3 次的
确认路径。确认前最多允许 3 帧短暂缺失，确认后最多容忍 2 帧候选波动。
该轨迹独立于其他信标，因此三个灯中任意 1、2、3 个亮均可检测。

## 上位机适配

`algorithm/host` 只模拟板端类型、Flash、摄像头和 Cortex-M4 DSP 语义，
并向 BeaconImageAnalyzer 导出检测结果、参数、二值图、地平线、车灯面积和
处理帧计数。每次送帧都会递增摄像头来源帧号，保持板端 100 Hz 版本的
新帧锁存行为。

适配器只在公共渲染坐标中转换 X 轴方向，不修改板端算法输出。二值图通过
板端 `image_prepare_stream_frame()` 生成，生成后恢复内部原始帧和图传模式。

## 使用

在 BeaconImageAnalyzer 中加载本目录 `前后摄`。实例支持 188x120 原始灰度
图、信标圆、车灯旋转框、二值图和地平线覆盖渲染。
